
# Battery Materials Research Project

## Research question

How can computational analysis help evaluate trade-offs between battery technologies, and what can materials science tell us about their potential for future energy storage?

## Aim

To investigate battery technologies using published evidence, Python-based data analysis and a transparent decision-support model.

## Technologies under investigation

- Lithium iron phosphate (LFP)
- Nickel-manganese-cobalt (NMC)
- Sodium-ion batteries
- Solid-state batteries

## Methods

- Scientific literature review
- Data collection and validation
- Python and pandas data analysis
- Matplotlib visualisation
- Weighted decision modelling
- Sensitivity analysis
- Streamlit dashboard development

## Project status

In development.

## Reproducibility

Python dependencies are listed in requirements.txt.
The project is intended to run in an isolated Python environment.

## Scientific integrity

Published measurements will be attributed to their sources.
Missing values will not be invented, and model assumptions and
limitations will be documented.
